This is the List of commands executed for this Assignment:-

1.	Verify if master is in clean state.

git checkout main
git status


2.	List out all the available branches.
git branch -a


3.	Pull the remote git repository to the master
git pull origin main


4.	Push the changes, which are pending from “Git-T03-HOL_002” to the remote repository. 
git checkout -b Git-T03-HOL_002
echo "This is a sample change" > sample.txt
git add sample.txt
git commit -m "Added Sample file"
git push origin Git-T03-HOL_002


5.	Observe if the changes are reflected in the remote repository.
git log origin/Git-T03-HOL_002 --oneline
